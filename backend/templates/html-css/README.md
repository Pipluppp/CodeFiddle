# HTML + CSS Template

This template keeps things intentionally bare-bones so you can focus on markup and styles.

## Getting started

```bash
npm install
npm run dev
```

The `dev` script launches the [serve](https://www.npmjs.com/package/serve) CLI, which hosts the folder as static files. The default `start` command simply re-routes to `npm run dev`, so either command works in local development and inside the CodeFiddle sandbox. Feel free to expand the template with additional assets or scripts as your project evolves.
