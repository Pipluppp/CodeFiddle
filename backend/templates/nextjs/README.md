# Next.js App Router Starter

This template mirrors the developer experience of `create-next-app` while staying intentionally compact. It ships with TypeScript, the App Router, and a few opinionated defaults so you can focus on shipping features fast.

## Getting started

```bash
npm install
npm run dev
```

Once the dev server boots, open http://localhost:3000 to explore the demo page. Update `app/page.tsx` or add your own routes under the `app/` directory and Next.js will hot-reload your changes.

## Included goodies

- Strict TypeScript configuration with path aliases.
- Metadata-ready layout component and a friendly landing page.
- Minimal styling in `app/globals.css` so you can opt-in to your favourite design system later.

Happy shipping!
