# Node.js template

This folder contains the Node.js starter used by CodeFiddle playgrounds. It follows the lightweight CodeSandbox approach while relying solely on the modern Node runtime.

## Getting started

1. (Optional) Run `npm install` if you plan to add packages.
2. Start the server with `npm start` (or `npm run dev` if you prefer the familiar alias).
3. Visit `http://localhost:3000` to see the response, then edit `index.js` and save to watch the server restart automatically.

## Project structure

- `index.js` boots a simple HTTP server and logs runtime details when it starts.
- `package.json` exposes a single `start` script that uses the built-in `node --watch` flag.
